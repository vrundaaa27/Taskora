# 🌸 Taskora

Taskora is a simple and user-friendly To-Do List web application that helps users organize and manage their daily tasks.

## ✨ Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks by All, Active, and Completed
- Clear all completed tasks
- Task counter to show remaining tasks
- Tasks are saved using Local Storage
- Responsive design for mobile screens
- Pastel-themed user interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage
